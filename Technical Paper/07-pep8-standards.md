# PEP-8 Standards Summary

PEP-8 is the official style guide for writing Python code, aimed at improving readability and consistency across the Python community. Following it makes code easier to read, review, and maintain, especially in team environments.

## Key Guidelines

* Use 4 spaces per indentation level, not tabs.
* Limit lines to a maximum of 79 characters where practical.
* Use `snake_case` for variable and function names, and `PascalCase` for class names.
* Use two blank lines between top-level function and class definitions.
* Add a single space after commas and around operators.
* Import statements should be on separate lines and placed at the top of the file.
* Use meaningful, descriptive names instead of single letters, except for simple loop counters.
* Write docstrings for modules, classes, and functions to document their purpose.

Following PEP-8 does not change how code executes, but it significantly improves collaboration since most Python developers and tools such as linters expect this convention.
